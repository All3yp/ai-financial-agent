# Local Verification

This verification distinguishes tests across implementation, interface, and live external services. It does not certify model quality, paid data sources, historical data fidelity, or production deployment.

## Reproducible Commands

In this milestone, all 184 tests pass, complete TypeScript type-checking passes, and the production build passes. The editor displays zero diagnostics or errors. Project lint warnings remain possible and are not equivalent to compilation failures.

```sh
pnpm test
pnpm typecheck
pnpm build:app
pnpm agent:analyze --input docs/examples/quantitative-fixture.json --mode=quantitative
```

`build:app` does not run migrations. `pnpm build` migrates the configured database before building; do not run `pnpm build` as a simple verification command against an unauthorized database.

## Verified User Interface

The `/agents` dashboard was served locally at `http://localhost:3011`. The existing automatic session flow was used without bypassing authentication. The synthetic fixture in the [examples](examples/README.md) directory was submitted to the live local endpoint, which executed calculations without calling an LLM or external data source.

- Empty state with execution and export buttons disabled.
- Fixture upload yielded output consistent with the CLI: Portfolio value USD 144, VaR USD 14.4, CVaR USD 28.8, maximum drawdown 28%, and three historical horizons.
- Warnings and limitations are displayed, including the 20-return sample warning.
- Clear action returns the UI to the empty state.
- Invalid JSON displays an error state and keeps export disabled.
- 1440x1000 desktop and 390x844 mobile viewports were inspected via screenshots and DOM measurements, showing no horizontal overflow or UI clipping.
- The export button generates a `blob:` download URL named `quantitative-2026-09-21.json`. The downloaded file matches CLI output for the versioned fixture bit-for-bit. It contains only synthetic `TEST_*` results, is ignored by Git, and does not replace the reproducible input `docs/examples/quantitative-fixture.json`.

No real financial data or secrets were sent to providers. Accessing the application may create automatic local identities and database sessions; no migrations or persistent portfolio ingestion took place.

## Fixed Regressions

The Monitor agent reads the normalized price envelope, selects the latest valid observations by date, and handles zero current ratios gracefully. Analysis preserves peer metrics and uses distinct bull/bear perspectives. Mocked unit tests cover contracts, not the analytical output quality generated by live LLMs.

Chat connects the AI SDK stream to the client and preserves prompt text and attachments when delegating subtasks. Text protocol tests use mocked model responses. No live LLM keys were used to validate output quality or third-party compatibility.
